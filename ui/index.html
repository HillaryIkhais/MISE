The engine reads the case state and decides the one next phone action. Call the supplier. Extract the commitment. The gate decides whether it is enough.

The CONTRACTOR protocol

MISE enforces a simple rule: no phone statement moves the case unless it clears a gate. The gate checks what was said, what was extracted, and whether the evidence is sufficient.

# verify_call — the CONTRACTOR gate
def verify_call(state, transcript, structured, confidence, source):
  if not COMMITMENT_PATTERN.search(transcript):
    return rejected("NO_EXPLICIT_COMMITMENT")
  if not structured.get("window"):
    return rejected("DELIVERY_WINDOW_MISSING")
  if not CLOCK.search(structured["window"]):
    return rejected("UNSPECIFIED_DELIVERY_TIME")
  if confidence < 0.5:
    return rejected("LOW_CONFIDENCE")
  return accepted(to_state="COMMITMENT_ACCEPTED")

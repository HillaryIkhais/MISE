Layer 01 — Move the case

The recovery engine

The engine reads the case state and decides the one next phone action. The first call's answer determines the second; the second determines the third. CALL-E performs the calls; the result feeds the gate.

# engine decides what to ask next
action = case.next_action()
# CALL-E does the talking
result = call_e_call(action["goal"], action["to"])
# gate decides whether it is enough
verdict = verify_call(case.state, result)
Layer 02 — Prove the move

The evidence gate

Every transition is backed by what a human actually said — exact statement, extracted commitment, date, confidence, call ID. Append-only, hash-linked. The board can be verified, not just claimed.

if verdict.accepted:
    case.advance()
else:
    # BLOCKER_UNCONFIRMED · PROVIDER_HEDGED
    # UNSPECIFIED_FIX_TIME · PROOF_NOT_TRUSTED
    # board does not move

The reusable primitive

CONTRACTOR — a commitment protocol for phone agents.

One input, one output, one rule. A phone-derived claim becomes evidence only when it satisfies the gate; a state transition cannot occur without an accepted commitment.

# CONTRACTOR · the primitive
from contractor import verify_call

verdict = verify_call(state, transcript, extracted, confidence, source)

# verdict.accepted → {accepted: True, to_state, step_type}
# verdict.rejected → {accepted: False, reasons: [CODE]}

if verdict["accepted"]:
    case.advance(verdict) # board moves, ledger appends
